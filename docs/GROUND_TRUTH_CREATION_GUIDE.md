## Overview

This package contains pre-segmented microglia masks for one fish, generated by our automated pipeline (MONAI skin removal, Cellpose-SAM segmentation, Krendl merge corrections). These masks are a **best-effort starting point**, not the final answer.

**Your task:** review and correct these masks so they become the definitive ground truth used to train and validate the microglia segmentation model.

All corrections are done in **napari** with the **ZF-Microglia-AI** plugin (the "ZF-Microglia-ToolKit" panel). The plugin automates most of the work: it protects the skin as its own label, re-fits every cell to the real signal, and gives you a report pointing at the cells that most need a human look. Your job is mainly to check that report and fix what it can't.

## Package Contents

Every file in the package starts with the fish's own identifier (the "stem", e.g. `NT39-3dpf-Crispr-ctrl-D1F4_2024-09-05_15.38.01`):

| File | Description | Use |
|------|-------------|-----|
| `<stem>_cp_corrected.tif` | Cellpose-SAM labels after the automated corrections | **START HERE** — the labels you correct |
| `<stem>_original.tif` | Raw microglia channel, nothing removed | **Signal layer** for Protect Skin and every correction (Step 7) |
| `<stem>_brain_only_ExtRm.tif` | Microglia channel with everything outside the brain removed | Image to correct against |
| `<stem>_brain_mask.tif` | Brain mask | Needed for Protect Skin as Label (Step 7) |
| `<stem>_cp_masks_3D.tif` | Raw Cellpose-SAM output, before merging (only if included) | Reference only |
| `<stem>_autocorrect_report.txt` | Report of the automated correction of these labels | Shows which cells need a closer look ([how to read it](#reading-the-auto-correct-report)) |
| `<stem>_cell_statistics.csv` | Label, volume, centroid, bounding box per cell | Quick reference |
| `GROUND_TRUTH_CREATION_GUIDE.md` | This guide | |

**Why two images?** Skin protection reads the real signal *outside* the brain, and in `_ExtRm` everything outside the brain has already been set to zero. `<stem>_original.tif` is the same channel with nothing removed, so it is the one the plugin reads its signal from. If a package has no `_original.tif`, open the fish's original `.ims` instead and use its microglia channel (usually `ch1`) wherever this guide says `_original`.

**Before you start, read `<stem>_autocorrect_report.txt`:** it already lists the cells corrected jointly with a neighbour, the cells touching skin, and possible non-microglia blobs.

## Software Setup

### First time

Install the ZF-Microglia-AI plugin and its conda environment (`zf-microglia-ai`) following **Section 2 (Installation)** of the plugin's own `GUIDE.md` / `GUIDE.pdf`:
https://github.com/CTichy/ZF-Microglia-AI

### Every time (Steps 1-4 of the workflow)

1. Open a terminal and activate the environment:
   ```bash
   conda activate zf-microglia-ai
   ```
2. If the plugin needs an update, go to your local copy of the plugin and pull the latest version:
   ```bash
   cd "<path to your ZF-Microglia-AI folder>"
   git pull
   ```
   (For example: `cd '/Users/<you>/Documents/.../ZF-Microglia-AI'`.)
3. Start napari:
   ```bash
   napari
   ```
4. Open the plugin: **Plugins → ZF-Microglia-ToolKit**.

## Labels Layer Basics

The masks are integer-labelled 3D volumes: every value is one object, and the same value across Z-slices is one 3D object.

- **0** = background
- **1, 2, 3, ...** = individual cells
- **-1** = skin (created by Protect Skin as Label, Step 7)

### napari Labels tools

| Shortcut | Tool | Function |
|----------|------|----------|
| `1` or `E` | Eraser | Set pixels to background (0) |
| `2` or `P` | Brush | Paint the current label |
| `4` or `F` | Bucket (fill) | Fill a region with the current label |
| `5` or `L` | Picker | Click to select the label under the cursor |
| `6` or `Z` | Pan/Zoom | Navigate without editing |
| `M` | New label | Set the current label to the next unused ID |
| `-` / `=` | | Decrease / increase the current label ID |
| `[` / `]` | | Decrease / increase brush size |
| `B` | Preserve labels | Toggle "don't overwrite other labels" |
| `Ctrl+Z` | Undo | Undo your last paint / fill / erase |

### Layer controls you will use

| Control | Meaning |
|---------|---------|
| **contiguous** | Bucket fills only the connected region you click, not every pixel with that value |
| **n edit dim** | 2 = a click edits only the current slice; 3 = a click edits through all slices |
| **show selected** | Display only the currently selected label |

> **Keep `n edit dim` at 2 for normal correction.** The plugin sets it back to 2 on the Labels layer you are editing whenever the layer list changes, as a safeguard. Only set it to 3 deliberately, for the relabelling in Step 8, and check it still says 3 right before you click.

## Correction Workflow (Steps 1-11)

Steps 1-4 are the [Software Setup](#software-setup) above.

### Step 5 — Open the image, brain mask and labels

All in the **Skin Remover** tab of the plugin:

1. **Open TIF / IMS file** → `<stem>_original.tif` (the raw microglia channel).
2. **Open TIF / IMS file** → `<stem>_brain_only_ExtRm.tif`.
3. **Open TIF / IMS file** → `<stem>_brain_mask.tif`. It opens as an Image layer, so convert it: right-click the layer in the layer list → **Convert to Labels**.
4. Select the `_ExtRm` layer as the active layer, then **Load Labels layer (.tif)** → `<stem>_cp_corrected.tif`.

### Step 6 — Background option

In the **Skin Remover** tab, select background option **1 — Remove background outside brain**. (This setting is only read by **Run Skin-Remover**, which you don't run here, so it has no effect on the steps below.)

### Step 7 — Protect the skin as label -1

1. Go to the **Edit MG Labels** tab.
2. At the top, in **Layers and label(s) being edited**, make sure the correct layers are selected (the plugin pre-fills the brain mask and labels, but not the `_original` layer — pick that one by hand):
   - **Signal layer** = `<stem>_original` (the raw channel), **not** the `_ExtRm` layer
   - **Labels layer** = the labels you loaded in Step 5
   - **Brain mask layer** = the brain mask you converted in Step 5
3. Scroll down to **Protect Skin as Label** and click it.
4. **Wait until it is done** (about 7 minutes for a full fish). It first runs a contrast sweep on about 20 cells to find the contrast/brightness setting of the raw signal that best fits the labels Cellpose-SAM generated, lowers it by **Reduce best_lo by** (default 2; e.g. swept 104 → `lo=102`), then labels everything outside the brain as skin (**-1**) at that setting and removes small stray skin fragments. It also sets the `_original` layer's contrast to that value.
5. Hide the other layers and check the skin label in **3D**: every slice should carry skin.

#### Correcting a slice that is missing skin

If a slice has no skin (or is clearly wrong):

1. Select the skin label: in **Edit MG Labels**, set **Label A** to **-1**.
2. Go to a slice directly above or below the missing slice that has correct skin.
3. Click **Copy Label to Adjacent Slice**, choosing **Next slice (Z+1)** or **Previous slice (Z-1)** so it lands on the missing slice.
4. Go to the missing slice and correct the skin there in 2D: **Correct Label** with **Correction mode** = **2D (current slice only)**, Label A = -1.
5. Repeat for every missing slice.

### Step 8 — Find cells that were labelled as skin

Protect Skin can absorb a real cell sitting near the skin. Check for this before correcting anything else:

1. **Duplicate** the `<stem>_original` layer (right-click → Duplicate Layer) and change the contrast/brightness of the **copy** until you can see all your cells well. Leave the original layer at the contrast the sweep set — the correction tools read their threshold from it.
2. Select label **-1** and tick **show selected**.
3. Look for cells near the skin, or any other blob, that ended up as part of skin.
4. Sort the cells: **Resort Labels** with **Sort by = Centroid Z**.
5. Choose a label number bigger than the highest cell number and set it as the current label (the next unused number; `M` does this).
6. Tick **contiguous** and set **n edit dim** to **3**.
7. With the **bucket**, click the blob that was recognised as skin to relabel it as a cell.
8. Repeat for every other cell that was taken as skin, with a new label number each time.
9. Set **n edit dim** back to **2**.

### Step 9 — Correct all labels: Auto-correct Labels

In **Edit MG Labels**, click **Auto-correct Labels**. It reuses the skin you already protected, re-fits every cell to the signal (cells touching the skin in 2D, all others in 3D), removes debris, and writes a report in the log box. See [Reading the Auto-correct Report](#reading-the-auto-correct-report) for what to look for.

### Step 10 — Correct single cells

Go through the cells the report flags, then the rest. See [Correcting Single Cells](#correcting-single-cells).

### Step 11 — Save

See [Saving the Ground Truth](#saving-the-ground-truth).

## Reading the Auto-correct Report

A typical report (shortened; the explanations on the right are not part of it):

```
Auto-correction: lo=102.4, adjusted -3 from the swept 105.4 (calibration mean IoU=0.888, 289 samples)
Skin was ALREADY protected as label -1 (5,048,915 voxels) -- reused exactly as it was, not re-protected or re-trimmed.
Cells resorted by Centroid Z before correction (80 cell(s)).
Cell-by-cell correction (Centroid-Z order): 80/80 corrected (10 touching skin, corrected in 2D against it; the rest in 3D)

Possible NON-microglia blob(s) -- 2 cell(s) with >= 40% outside the brain mask and/or of their surface
against skin (macrophage or leftover skin?). REPORT ONLY -- nothing was removed or changed:
  label 29: 77% of volume outside brain (82,702 vox, centroid z=48 y=479 x=1369)
  label 74: 46% of volume outside brain (62,878 vox, centroid z=92 y=1955 x=999)

--- Label 1 ---
Auto-grow (3D, per-slice): base pad=15px, up to 20 attempt(s) per slice, group=[1]
No slice needed more than the base pad.
Slice(s) that took more than one pass to settle: 0: 2 pass(es), 1: 2 pass(es), ... 12: 2 pass(es)
Converged -- no part of the result touches the padded region's own edge.
Debris removed: 54 px

--- Label 2 ---
Auto-grow (3D, per-slice): base pad=15px, up to 20 attempt(s) per slice, group=[2, 4]
...

--- Label 11 ---
Auto-grow (2D per-slice, jointly resolved against skin label -1): group=[-1, 11]
Slice(s) that needed a bigger pad: 19: 25px, 20: 20px, 22: 30px, ...
Slice(s) that took more than one pass to settle: 19: 3 pass(es), 20: 10 pass(es), 21: 20 pass(es), ...
Converged -- no part of the result touches the padded region's own edge.
Debris removed: 0 px
```

What to look for:

| Line | Meaning | What to do |
|------|---------|------------|
| `group=[1]` | The cell was corrected on its own | Normal; spot-check |
| `group=[2, 4]` | Label 2's bounding box is near label 4, so their boundary was corrected jointly | **Check both cells carefully**, especially where they meet ([case b](#b-a-cell-touching-another-cell)) |
| `group=[-1, 11]` | The cell touches the skin, so it could only be corrected in 2D | **Review and correct this cell in 2D** ([case e](#e-a-cell-touching-the-skin)) |
| `Possible NON-microglia blob(s)` | Cells mostly outside the brain or mostly against skin (macrophage or leftover skin?) | Report only: look at each one and decide whether it is a real microglia |
| `Debris removed` | Small loose fragments of that label removed after correction | Normally nothing to do |

## Correcting Single Cells

All tools below are in the **Edit MG Labels** tab and act on **Label A** (and **Label B** where needed) from the selector at the top. Click a label in the viewer, then **Use selected** next to Label A or B to fill it in.

### a) A single cell not touching anything

1. Check the cell in 2D and 3D for holes.
2. If a hole was not filled automatically, fill it in 2D with the **bucket**.

### b) A cell touching another cell

1. Check the boundary to the other cell(s) in 2D and 3D.
2. Make a broad, rough correction with the **eraser** to separate the two labels.
3. Click **Correct Adjacent Labels** (works in 2D, on the current slice):
   - **Label A** = one cell
   - **Label B** = the other cell, which is accommodated to Label A
4. If not satisfied, repeat, or correct manually in 2D with the brush / bucket / eraser.
5. Review and check for holes; fill if necessary (case a).

### c) Two labels that are actually one cell

1. **Label A** = the first piece, **Label B** = the second piece.
2. Click **Join Labels** (Label B becomes Label A).
3. The joined label is still separated by a gap, so correct it in 3D: **Correct Label** with **Correction mode** = **3D (whole cell)**, Label A = the joined label.
4. Review and check for holes; fill if necessary (case a).

### d) Several cells recognised as one

1. **Label A** = the merged label.
2. Set **Split into N parts** to the number of cells it should be.
3. Click **Split Label**.
4. Review and check for holes; fill if necessary (case a).

### e) A cell touching the skin

**Review and correct this cell in 2D only.** Otherwise the same as case b:

1. Make a broad, rough correction with the **eraser** to separate the cell from the skin.
2. Click **Correct Adjacent Labels** (works in 2D, on the current slice):
   - **Label A** = **-1** (skin)
   - **Label B** = the cell of interest
3. If not satisfied, repeat, or correct manually in 2D with the brush / bucket / eraser.
4. Review and check for holes; fill if necessary (case a).

## Saving the Ground Truth

1. In **Edit MG Labels**, click **Save Labels**.
2. If this is ground truth, add `_GROUND_TRUTH` to the end of the file name:

```
START FILE:  NT39-3dpf-Crispr-ctrl-D1F4_2024-09-05_15.38.01_cp_corrected.tif
SAVE AS:     NT39-3dpf-Crispr-ctrl-D1F4_2024-09-05_15.38.01_GROUND_TRUTH.tif
```

The plugin also autosaves the Labels layer you are editing every 30 minutes (Sweeps & Utilities → General → Autosave Labels Layer), but that is only a crash safety net; always save explicitly with Save Labels when you finish.

## Quality Checklist

Before finalizing the ground truth, verify:

### Skin
- [ ] Every slice carries skin (-1), checked in 3D
- [ ] No real microglia remains part of the skin label (Step 8)

### Cell Identification
- [ ] All true microglia are labelled (no missed cells)
- [ ] No debris/artifacts remain labelled
- [ ] Every "Possible NON-microglia blob" from the report was checked
- [ ] Each microglia has its own label ID
- [ ] No cells are merged into one label (case d)
- [ ] No cell is split into several labels (case c)

### Boundaries
- [ ] Cell boundaries follow the real cell edges
- [ ] Every `group=[A, B]` pair from the report was checked where the cells meet
- [ ] Every cell touching skin (`group=[-1, N]`) was reviewed in 2D
- [ ] No holes inside cells

### 3D Consistency
- [ ] Same cell has the same ID in all slices
- [ ] No "floating" pieces disconnected in Z

### File
- [ ] Saved with Save Labels
- [ ] Filename ends with `_GROUND_TRUTH.tif`
- [ ] The saved file reloads correctly in napari (Load Labels layer)

## Technical Specifications

### Voxel Dimensions
| Axis | Resolution | Unit |
|------|------------|------|
| X | 0.174 | µm/pixel |
| Y | 0.174 | µm/pixel |
| Z | 1.0 | µm/slice |
| **Anisotropy** | 5.75 | Z/XY ratio |

### Volume Dimensions
- Typical size: 101 x 2048 x 2048 (Z x Y x X)
- Approximately 400 million voxels per volume

### Ground Truth File
| Property | Value |
|----------|-------|
| Format | TIFF |
| Data type | 32-bit signed integer (int32), as written by Save Labels |
| Values | -1 = skin, 0 = background, 1+ = cell IDs |
| Dimensions | Same as the input (Z, Y, X) |

### Pipeline Used to Generate the Initial Masks
1. **MONAI skin removal** — 3D U-Net brain mask
2. **Cellpose-SAM 3D** — fine-tuned on microglia ground truth
3. **Krendl corrections** — safe merge of fragments + large-contact merge
4. **Plugin auto-correction** — per-cell contrast-calibrated correction and contour sanding

## Troubleshooting

### "The brain mask can't be selected as Brain mask layer"
- It is still an Image layer. Right-click it → **Convert to Labels** (Step 5).

### "Protect Skin finds no skin / skin looks empty"
- The Signal layer is probably the `_ExtRm` layer, which is zeroed outside the brain. Select `<stem>_original` as Signal layer (Step 7).

### "Protect Skin says skin is ALREADY protected"
- The layer already contains label -1, so it is never protected twice. To redo it from scratch, click **Remove Skin Label** first.

### "A bucket click changed the whole stack / only one slice"
- Check **n edit dim** (2 = current slice, 3 = all slices) and **contiguous** before clicking. `Ctrl+Z` undoes the click.

### "Labels disappear when I scroll"
- Normal: a cell only appears on the slices it spans.

### "napari crashes"
- Close other applications to free memory and restart napari. Reload your last saved labels, or the autosaved copy, with **Load Labels layer (.tif)**.

For anything else, see the Troubleshooting section of the plugin's own `GUIDE.pdf`.
